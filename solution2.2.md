 I created a resume-style personal introduction webpage. I used my name in the main heading with an h1 tag. I wrote an introduction paragraph in the About Me section using the p tag and used br for line breaks to organize the text. I created separate sections for education, skills, and hobbies using div tags to group related content. I used headings from h1 to h6 appropriately to show hierarchy — h2 for main sections, h3 and h4 for sub-sections, and h5 and h6 for smaller headings. I used hr tags to add horizontal lines as separators between sections. To highlight important text, I used strong for bold, em for emphasized text, and i for italic style. I also used span tags to style inline content within paragraphs. This assignment helped me learn how to structure a personal webpage using various HTML tags.
